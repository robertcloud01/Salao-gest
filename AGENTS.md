# ATELIER — Coding Agent Design Directive

Read: https://github.com/Leonxlnx/taste-skill and the `design-taste-frontend` SKILL.md, especially place/category rules.
Install where available:
```sh
npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"
```

Style direction:
- Industry: premium beauty salon (place), not a tech SaaS landing page.
- Identity: editorial, tactile, aspirational, feminine without clichés; warm cream, espresso brown, chestnut, soft gold.
- Photography first. Absolutely no aurora shaders, animated particles, or WebGL backdrops. React Bits for quiet interactions that don't compete with beauty photography.
- Genuine salon images for commercial use; current Unsplash URLs are demonstrative placeholders.
- No fake social proof, invented award badges, addresses, contact numbers, or analytics.
- UI copy in Brazilian Portuguese; direct, human, refined.
- Booking and back office must share the same Supabase records, validate server-side and handle race conditions.
- Verify 1440x900, 1024x768, 768x1024, 390x844, 320x640, keyboard, reduced motion, mobile dialogs/forms.
- Site usability and actual secure booking are more important than decoration.

Current build is not the finished product; see README production backlog. Do not claim Taste Skill's automation has run unless there is an actual log/screenshots.
